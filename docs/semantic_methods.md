# Методика смыслового анализа статей

Описание того, как считаются все числа в отчёте «Смысловой анализ статей», с формулами,
источниками данных, порогами и ограничениями. Состояние на 17.10.2026 (ветка `semantic-analysis`).

Код: `app/services/article_parser.py` (разбор), `app/analysis/lexical.py` (дословные совпадения),
`app/analysis/semantic.py` (эмбеддинги), `app/analysis/claims.py` (утверждения, LLM).
Скрипты: `scripts/parse_articles.py`, `semantic_articles.py`, `synthetic_check.py`,
`claims_check.py`, `build_report_data.py`.

## 2. Разбор статьи (без моделей)

Структура восстанавливается по вёрстке PDF (PyMuPDF): кегль, жирность, капс, координаты строк.

1. **Строки.** Куски текста на одной высоте склеиваются в строку (выключка по ширине дробит строку
   на слова). Чинятся два дефекта текстового слоя: cp1251, прочитанный как latin-1
   («Îïðåäåëåíèå» → «Определение»), и разрядка («П р и м е р» → «Пример»).
2. **Колонтитулы и номера страниц** отбрасываются: строка в верхних/нижних 9% страницы, повторённая
   на ≥2 страницах; строка на одной высоте на ≥3 страницах; голый номер первой/последней строкой.
3. **Абзацы**: новый абзац при увеличенном интервале (> 1,6 × обычного, с поправкой на кегль),
   отступе первой строки относительно соседних строк, короткой строке с точкой в конце, смене
   кегля, стиля, письменности (кириллица/латиница), «таблица/текст», перед словами-якорями
   («Аннотация», «Ключевые слова», «Список литературы»…). Переносы слов склеиваются.
4. **Заголовки**: отдельная строка жирным, крупнее или капсом, правдоподобная (не подпись к
   рисунку, не пункт списка, не формула, не жирное предложение), за которой идёт текст ≥100 знаков.
   Заголовок в начале абзаца — жирный/курсивный фрагмент с точкой или слово из словаря
   («Введение.», «Выводы.»).
5. **Шапка.** Два режима: по «Ключевым словам» (современные журналы) или по названию рядом со
   строкой авторов (старые журналы без меток). Всё до шапки — хвост предыдущей статьи журнала;
   ещё одна связка «авторы + НАЗВАНИЕ» дальше — следующая статья; обе отбрасываются с предупреждением.
6. **Литература** — от заголовка «Список литературы/Литература/References…» или, без заголовка, от
   «1. …» с признаками библиографического описания. Пункты делятся по номеру (следующий = +1, тот же
   стиль «[n]»/«n.») или, без номеров, по висячему отступу.
7. **Язык**: если в тексте вне шапки > 60% букв латинские — статья английская.

В анализ идут только абзацы тела и аннотация; шапка, литература, таблицы, подписи, сноски
(кегль < 0,75 основного) и английские абзацы — нет.

## 3. Фрагменты

Единица смыслового сравнения — **фрагмент** 300–1500 знаков: короткие абзацы одного раздела
склеиваются до ≥300 знаков, длинные режутся по предложениям до ≤1500. Короткий абзац даёт шумный
вектор, слишком длинный — размытый.

**Формульный фрагмент** исключается из всех метрик:

  доля_букв(x) = (число кириллических и латинских букв) / (число непробельных символов),
  фрагмент формульный, если доля_букв < 0,70.

Порог 0,70 — 5-й перцентиль по 430 фрагментам; всё ниже при просмотре оказалось формулами,
таблицами чисел или кодом. Обычная проза — около 0,95.

## 4. Эмбеддинги и косинусная близость

Каждый фрагмент x переводится моделью `text-embedding-qwen3-embedding-0.6b` (локально, LM Studio)
в вектор и нормируется:

  e(x) = v(x) / ‖v(x)‖,   cos(x, y) = e(x) · e(y)  ∈ [−1, 1]  (на практике 0,2–1,0).

Близость отражает сходство **смысла**, а не слов: пересказ другими словами даёт высокую близость.

## 5. Метрики

Обозначения: статья A — множество её фрагментов (без формульных); C — корпус.

### 5.1. Сходство статей (покрытие)

  cov(A → B) = (1 / |A|) · Σ_{a ∈ A} max_{b ∈ B} cos(a, b)

«Насколько содержание A уже есть в B»: для каждого фрагмента A берётся самый похожий фрагмент B,
результат усредняется. Мера **асимметрична**: короткая статья, целиком пересказанная в длинной,
даёт высокое cov(короткая → длинная) и низкое обратное. На карте строка — A, столбец — B.

### 5.2. Новизна

Для фрагмента a статьи A, корпус C = все фрагменты всех **других** статей (leave-one-out):

  nov(a) = 1 − max_{c ∈ C} cos(a, c),     nov(A) = (1 / |A|) · Σ_{a ∈ A} nov(a)

0 — такой фрагмент (по смыслу) уже есть в корпусе. Новизна **относительна корпусу**: статья, у
которой в корпусе нет соседей по теме, получает высокую новизну, даже если пересказывает учебник.

### 5.3. Смысловые повторы внутри статьи

Пара фрагментов (aᵢ, aⱼ) одной статьи — повтор, если

  |i − j| ≥ 2  (соседние фрагменты продолжают одну мысль — не считаются),
  ни один не аннотация (аннотация обязана пересказывать статью), ни один не формульный,
  cos(aᵢ, aⱼ) ≥ τ,  τ = 0,82.

  повторы(A) = |{фрагменты, входящие хотя бы в одну такую пару}| / |фрагменты тела A|

τ = 0,82 — верх ~1% распределения несоседних пар внутри статей (5251 пара: p95 = 0,70, p99 = 0,79);
все пары ≥ 0,83 при чтении оказались пересказом.

### 5.4. Дословное совпадение (шинглы)

Текст → основы слов (первые 6 букв слова, грубая замена стемминга: «миварных»/«миварные» →
«миварн») → множество последовательностей по 5 основ подряд S(x).

  cont(x, y) = |S(x) ∩ S(y)| / |S(x)|,     дословно(x, y) = max(cont(x, y), cont(y, x))

Ловит копипаст и слегка правленный текст, но не пересказ. В паре «смысл высокий, дословно ≈ 0» —
пересказ; «оба высокие» — копирование.

### 5.5. Самоцитирование

  самоцит(A) = |{пункты литературы, где встречается фамилия автора A}| / |пункты литературы A|

### 5.6. Проверка, различает ли модель темы

  среднее cov(A → B) по парам одной группы  vs  по парам разных групп;
  доля статей, у которых argmax_B cov(A → B) — статья той же группы.

## 6. Уровень утверждений (LLM, прототип)

Модель `qwen3.6-35b-a3b` (локально; думающая модель — рассуждение отключено закрытым блоком
`<think></think>` в шаблоне запроса, иначе оно съедает весь лимит 4096 токенов). Температура 0;
три повтора без кэша дали одинаковые ответы.

1. **Утверждения абзаца**: модель разбивает абзац на атомарные утверждения и даёт каждому тип:
   *результат* (что получено авторами), *факт* (определение, метод, свойство, чужой результат),
   *общее* (оценки и общие слова, которые нельзя проверить), *связка* (анонс, план, метатекст).

     плотность(абзац) = 1000 · (число утверждений типа «результат» или «факт») / (знаков в абзаце)
     доля_общих(абзац) = (число «общее» + «связка») / (число утверждений)

   «Вода» — низкая плотность и высокая доля общих слов.
2. **Общие утверждения двух фрагментов**: модель сравнивает списки содержательных утверждений и
   для каждого утверждения A отвечает «да / частично / нет» — высказано ли **то же** утверждение
   (тот же объект, те же условия) в B.

     общая_доля(A, B) = (да + 0,5 · частично) / (число содержательных утверждений A)

3. **По статье** (прогон на 18 статьях, 558 абзацев, `scripts/claims_corpus.py`):

     плотность(статья) = 1000 · Σ(результат + факт) / Σ знаков абзацев,
     водянистые абзацы = доля абзацев, где (общее + связка) ≥ ½ утверждений.

   Результат: плотность 9,0–12,8 (медиана 10,7), водянистых абзацев 0–10%. Явно водянистых
   статей нет; вода сосредоточена в отдельных абзацах (введения, заключения с «перспективами»).
   Из 6 самых водянистых абзацев при чтении 4 — вода, 2 спорные, 1 ложное срабатывание
   (постановка задачи с формулами: символы формул увеличивают длину и занижают плотность —
   правильнее делить на число букв).

## 8. Согласованность метрик (`scripts/consistency_check.py`)

Ранговая корреляция Спирмена ρ между метриками статей (18 статей с уровнем утверждений; при
n = 18 |ρ| < ~0,47 не отличается от нуля) и проверка на абзацах (554 абзаца, новизна абзаца =
новизна фрагмента, в который он входит).

- **Новизна ≈ одиночество в корпусе**: ρ(новизна, сходство с ближайшей статьёй) = −0,92 по 36
  статьям. Самые «новые» — единственные статьи на свою тему (вероятности, экспертная система в
  обучении, QUBO).
- **Новизна не связана с «водой»**: ρ(плотность утверждений абзаца, новизна) = 0,03; медиана
  новизны водянистых абзацев 0,441, обычных 0,424. Абзац «большое внимание уделяется разработке
  обучающих программ… создано множество систем» (плотность 2,65) имеет новизну 0,537 — одну из
  самых высоких. Противоречие «много воды и высокая новизна» возникает систематически.
- **Метрики воды согласованы**: ρ(плотность, доля общих) = −0,70; ρ(водянистые абзацы, доля общих) = 0,65.
- Повторы и самоцитирование с новизной значимо не связаны.

**Как исправить** (не реализовано): считать новизну только по содержательным фрагментам
(с результатами и фактами); показывать опору в корпусе и писать «не с чем сравнить» вместо высокой
новизны у статей без соседей; не сводить метрики в одно число.

## 9. Что метод может и чего не может

**Может:**
- находить пересказ одной мысли другими словами внутри статьи и между статьями;
- отличать копипаст (высокое дословное совпадение) от пересказа;
- находить заимствованный фрагмент, если источник есть в корпусе;
- показывать, с какими статьями корпуса статья совпадает по содержанию;
- (уровень утверждений) находить «воду» — абзацы из общих слов без проверяемых утверждений.

**Не может (сейчас):**
- новизна **относительна корпусу**: без соседей по теме статья выглядит новой; абсолютной
  научной новизны метод не измеряет;
- эмбеддинги **не отличают «ту же мысль» от «той же узкой темы»**: две статьи одной школы по
  выпуклой оптимизации (разные теоремы) дают сходство 0,68–0,69, выше, чем миварные статьи с
  настоящим пересказом. На уровне утверждений направление верное (общая доля ~0,39 у миваров против
  ~0,17 у школы), но проверено на 5 парах — это не калиброванная метрика;
- параллельная структура (однотипные случаи в математике) выглядит как повтор;
- граница типов «результат/факт» у LLM размыта (общие сведения иногда помечаются «результатом»);
  на «воду» это не влияет, оба типа содержательные;
- достоверность утверждений, их значимость и правильность не оцениваются;
- сканы без текстового слоя не разобраны; работает только с русским текстом;
- все пороги подобраны на 25–36 статьях и одной модели эмбеддингов.

## 10. Стоимость

- Эмбеддинги: 1170 фрагментов — около 20 с (кэшируются, повторный прогон мгновенный).
- Утверждения: ~6–7 с на абзац (qwen3.6-35b-a3b без рассуждения, GPU 12 ГБ + ОЗУ).
  Статья ≈ 40–60 абзацев ≈ 5–7 мин; весь корпус (36 статей) ≈ 3 ч.
