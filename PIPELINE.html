8. Сценарии — что задействуется на каких книгах

СценарийКакие компоненты
Простая ВКР (Массель, Виды интерфейсов)эвристика ToC → regex mapping → fast_clean. LLM/OCR не вызываются вообще.
Книга со сложным ToC (Кениг)эвристика 0–2 → LLM extract_toc_json → regex + page-hint rescue → fast_clean
Книга с двумя ToC (Release It!)эвристика 36 → dedup → regex → раннее verify ловит 21 in-ToC → page-hint rescue → fast/LLM clean
Военный стандарт с List of Figures (MIL-STD)эвристика + terminator → 750 → regex → 0 miss
Битая кодировка (0e6e53b)garbage detection → glm-ocr распознаёт все страницы → эвристика по OCR-тексту → regex → fast_clean
Верхнеуровневый ToC (Иглмен)эвристика 6 → LLM-expand parts → regex + embedding rescue → LLM clean с защитой от CJK
Книга без ToC вообщеэвристика 0 → LLM 0 → (OCR если unreadable) → deep_scan если включён флагом
