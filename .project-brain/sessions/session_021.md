## Что сделано
- `static/article.html` переписана: шаги «1. С чем сравнивать» (корпус с темами, режим —
  карточки с пояснением, тема) → «2. Что проверяем» (перетаскивание PDF/DOCX); вступление
  «что вы получите»; итог — 4 карточки с подписями «что это значит» и «?» → справка;
  похожесть на корпус — одна полоса из 4 категорий (почти то же / близко / та же тема /
  не с чем сравнить) по доле текста; структура работы с полосами по разделам; подсветка
  абзацев (похожесть / повторы / дословно) с легендой словами; карточка абзаца с вердиктом
  простыми словами; выдвижная справка «Как читать результаты»; окно выбора документа с поиском.
  Светлая тема по умолчанию + тёмная. Ссылки `?corpus=&doc=&para=&mode=&help=1`.
- `app/services/article_docx.py` — DOCX по стилям заголовков (fallback — жирные короткие абзацы),
  титул → название/авторы, «Содержание»/«Реферат»/«Список источников»/«Приложение» — зоны,
  подписи и центрированные короткие строки пропускаются, пункты списка — к абзацу-вводу.
  API и corpus_build принимают DOCX.
- Парсер PDF (ВКР): строка оглавления с отточием всегда завершает абзац (раньше «ВВЕДЕНИЕ»
  со следующей страницы прилипало к оглавлению); «СОДЕРЖАНИЕ» и строки оглавления выкидываются;
  пункты «1) …»/«– …» после «…:»/«…;» присоединяются к абзацу.
- corpus_build MIN_BODY 3000 → 2500 [user]. Название документа без титула = имя файла.
- Корпуса пересобраны: «КиберЛенинка» 120, «Статьи этапа 2» 32, «Студенческие работы» 2.
