# Session 023 — 2026-10-18 — «вода» в сервисе, корпус ИИ/информатика/математика, разметка
← [session_022.md](./session_022.md)

## Session Intent
User: (1) кнопка «вода» на сайте + прогнать все существующие корпуса; (2) скачать много статей по
математике, информатике, ИИ; (3) страница разметки. Эмбеддер — ctx 8192 [user].

## Что сделано
- `app/analysis/water.py` — WaterJob: очередь абзацев → утверждения (qwen3.6, claims.py) → таблица
  para_claims (ключ sha1 текста), фоновый поток, смена моделей через lms CLI (unload all → LLM →
  после — эмбеддер ctx 8192), повтор запроса ×3. Вода = общие+связки ≥ 50% утверждений (как s018).
- article_report: к абзацу — профиль утверждений; сводка: watery_share, плотность и
  novelty_substantive — новизна только по абзацам с опорой и без воды (решение s019 реализовано).
- API: /api/water/{status,start,start-corpus,stop,profiles,pending}; загрузка нового файла во
  время проверки → 503 с объяснением.
- Страница: карточка «Вода» (кнопка, оценка времени, прогресс, «остановить»), режим подсветки
  «Вода», утверждения с типами в карточке абзаца, индикатор задачи в шапке, раздел справки.
- scripts/fetch_cyberleninka.py: режим журнала (номера — JSON в странице журнала, статьи —
  /api/issue/<id>/articles). Скачано 324+ статьи 2018–2026 из 9 журналов (Программные продукты и
  системы, Онтология проектирования, Программные системы, Известия ЮФУ (техн.), НТВ ИТМО, Вестник
  ЮУрГУ ВМИ, Мат. моделирование и числ. методы, Прикладная дискретная математика, Вестник СПбГУ
  ПМ-И-ПУ). Новый корпус «ИИ, информатика, математика» — 274 документа (50 пропущено: англ., сканы).
  document.journal — новая колонка (миграция ALTER TABLE).
- `app/analysis/labels.py` + `static/label.html` (+ /api/label/*): 48 пар (корзины близости
  0.70–0.95 + повторы внутри статьи) и 40 абзацев, ответы по имени разметчика, отчёт «человек
  против машины» после разметки; ссылка label.html?who=Имя.
