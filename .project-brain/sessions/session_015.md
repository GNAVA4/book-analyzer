## Что сделано
1. **Корпус.** КиберЛенинка: поиск через API отдаёт 0, зато работают страницы рубрик.
   Скрипт в scratchpad собрал ссылки (рубрики computer-and-information-sciences ×12 стр.,
   mathematics ×8), отбор по слагу, скачано 20 PDF в `articles_web/` (gitignored), с префиксом
   темы: nn 5, fuzzy 4, expert 3, ode 3, prob 2, graph 3. 3 из 20 — сканы без текстового слоя.
2. **Парсер на новых вёрстках — первая проверка провалилась честно:** 2/20 разобраны нормально.
   Причина — старые «Известия ТРТУ/ЮФУ» (2000-е): нет «Аннотация/Ключевые слова», шапка
   `[колонтитул] [УДК] [авторы] [НАЗВАНИЕ КАПСОМ] [аннотация без метки] [англ. блок] [текст]`,
   в файле хвост предыдущей и начало следующей статьи журнала, литература без заголовка.
   Доработки `article_parser.py`:
   - опора на НАЗВАНИЕ, если нет ключевых слов: `_title_candidates/_find_title_idx` (выделенный
     кириллический абзац 15–300 симв., +3 если рядом строка авторов, −2 если <3 слов — рубрика
     «Краткие сообщения»); `_header_start` — назад по УДК/авторам; всё раньше — чужое;
   - следующие статьи в файле: ещё одно «авторы + НАЗВАНИЕ (КАПС или крупнее)» дальше по тексту;
   - аннотация без метки: 1–3 кирилл. абзаца ≤1500 симв., за которыми англ. блок;
   - литература без заголовка `_unlabeled_refs_start` («1. …» с признаками описания: //, С. 12,
     М.:, год, изд + «2. …» рядом) во второй половине статьи;
   - колонтитулы вне полосы: одна строка на одной высоте на ≥3 стр.; номер страницы — если это
     первая/последняя строка страницы;
   - заголовок ≠ формула (≥60% букв, нет «=», есть слово из 3+ букв); имена-колонтитулы не заголовки;
   - англ. абзацы в теле (>80% латиницы) — `foreign_lang`, не текст статьи;
   - `_repair_text`: cp1251-как-latin-1 по участкам («Îïðåäåëåíèå»→«Определение», в т.ч. в строке
     с настоящей кириллицей), разрядка «П р и м е р»→«Пример»;
   - скан без текстового слоя (<200 симв./стр.) → `needs_ocr: True` + warning, без мусора.
3. **Смысловой слой** `app/analysis/semantic.py`: фрагменты 300–1500 симв. (`make_chunks`),
   `Embedder` (LM Studio, батчи по 32, дисковый кэш `.cache/embeddings.jsonl`, httpx trust_env=False),
   метрики coverage / novelty (leave-one-out) / redundant_pairs; формульные фрагменты исключаются
   (`is_formula`: доля кирилл./лат. букв < 0.70). Отчёт `scripts/semantic_articles.py`.
4. numpy 2.4.6 установлен в venv + добавлен в requirements.txt (файл в UTF-16 — сохранена кодировка).
