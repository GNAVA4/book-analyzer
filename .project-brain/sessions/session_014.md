  авторах, строки таблиц, подписи рисунков, выключка по ширине дробит строки на слова.

## Что сделано
- `app/services/article_parser.py` — алгоритмический парсер статьи (без моделей):
  строки с признаками вёрстки → колонтитулы (полоса верх/низ + повтор на ≥2 стр.) → абзацы
  (отступ первой строки ОТНОСИТЕЛЬНО соседних строк, интервал, короткая строка, якорные слова,
  смена письменности, смена «таблица/текст») → заголовки (стиль + правдоподобие + «за заголовком
  идёт текст ≥100 симв.») → разрез на статьи по русским «Ключевые слова» → зоны: шапка (название,
  авторы, УДК, аннотация, ключевые слова), тело (разделы), хвост (литература, прочее).
  Выход: dict + `to_xml_nodes` → тот же XML, что у книг (xml_builder).
- `scripts/parse_articles.py` — прогон папки → `articles_parsed/*.xml|*.json` + сводка.
- `app/analysis/lexical.py` + `scripts/analyze_articles.py` — лексический слой: шинглы 5 «основ»
  (первые 6 букв), containment между абзацами (внутри статьи и между статьями), доля текста,
  повторённого в корпусе, доля самоцитирования.
- `tests/test_article_parser.py` — 14 тестов (склейка переносов, правдоподобие заголовка,
  заголовок-в-абзаце, колонтитулы, висячий отступ, отступ первой строки, якоря, зоны+литература).
- `.gitignore`: `articles/`, `articles_parsed/` (локальные PDF и результаты, как test/).

## Ловушки сессии (не повторять)
- **Bash-инструмент разэкранирует `\\b` → `\b` (backspace, \x08)** при правке файлов через python-heredoc.
  Регэкспы молча перестали матчить («Резюме», «Ключевые слова»). Правило: правки кода — только
  Edit/Write (heredoc через cat НЕ спасает); проверять `s.count(chr(8)) == 0`.
  См. [[insight_2026-10-17_bash-tool-unescapes-backslash-b]]. Финальный скан app/scripts/tests — чисто.
- Мелкий кегль нельзя выкидывать до разметки зон: в тегировании аннотация 8pt и ключевые слова 7pt
  при теле 10pt. Мелочь убирается только из тела.
- Номер пункта литературы: новый пункт только при номере = предыдущий+1 И том же стиле («[n]» vs «n.»),
  иначе «3. - С.687-694.» внутри описания журнала режет пункт (поймал тест).
- pytest целиком падает на импорте openai из-за СИСТЕМНОГО прокси Windows (socks4://127.0.0.1:10808,
  не env). Запуск: `NO_PROXY='*'`.
- LM Studio: `lms ls` → «Timed out waiting for LM Studio daemon» — демон не стартует из CLI.
  Нужен запуск приложения пользователем.
