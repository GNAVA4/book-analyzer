## Как получать статьи с КиберЛенинки
- API поиска `POST /api/search` возвращает found=0 (нужны куки/токен) — не использовать.
- Работают страницы рубрик `/article/c/<рубрика>/<N>` → ссылки `/article/n/<slug>`;
  PDF: `/article/n/<slug>/pdf`. Пауза 1.5–2 с между запросами.
- Рубрики по умолчанию отдают в основном СТАРЫЕ статьи (2000-е, «Известия ТРТУ/ЮФУ»).

## What's dirty ⚠️
- **Сканы без текстового слоя**: 3 из 20 статей КиберЛенинки (0–6 симв. на 2–4 стр.).
- **Журнальная выгрузка = страницы журнала**, а не статья: в начале хвост предыдущей статьи
  (литература + сведения об авторах), в конце — начало следующей (в 10 из 17 файлов).
- Старые журналы: нет «Аннотация/Ключевые слова», аннотация без метки, англ. блок
  (авторы+название+аннотация) после русской шапки, литература часто без заголовка.
- Текстовый слой: cp1251, прочитанный как latin-1 («Îïðåäåëåíèå»), иногда вперемешку с нормальной
  кириллицей в одной строке; разрядка «П р и м е р»; формулы разваливаются на символы.
- Выключка по ширине дробит строку на отдельные слова (каждое — свой span/line в PyMuPDF).
