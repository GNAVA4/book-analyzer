# ADR 004: Этап 2 — семантический анализ (новизна/повторы/«вода») как отдельный слой после парсера

**Date:** 2026-10-17 (без изменений кода; постановка)
**Status:** Accepted (постановка); детали — [[plan_001_semantic_novelty_analysis]]

## Context
Парсер книг достиг приемлемого качества. Пользователь и научный руководитель ставят новую задачу:
численно сравнивать смысл фрагментов, оценивать новизну относительно корпуса и эталона, находить
повторы, «воду», стилистические сигналы. Первый реальный объект — сборник «МИВАР22» (439 стр.).

## Decisions (with provenance)
| Decision | Why | Source |
|---|---|---|
| Новизна = ДВА числа: покрытие эталона и объём «сверх эталона» (сумма — только справочно) | Одно число смешивает две независимые характеристики | [supervisor] идея, [user] выбрал два числа |
| Единица сравнения — атомарные утверждения; C = корпус (0), E = эталон (1) | Один механизм покрывает сценарии курсовых, миваров и роли абзацев | [supervisor] + [inferred] |
| Только русский язык | Объекты анализа русскоязычные | [user] |

| Детекция «сгенерировано ИИ» — не цель; стилистические сигналы — нужны | Надёжной детекции нет даже у коммерческих систем | [user] |
| Анализ — отдельный слой (вход XML/текст → JSON + HTML), книжный парсер не трогаем | Изоляция; решения этапа 1 остаются в силе | [inferred] |
| Скорость не оптимизируем на этапе исследования | Сначала понять, что возможно | [user] |

## Consequences
- ⚠️ Эталон «от нейросети» (сценарий B(2)) на локальной qwen-7B слабый → отложен.
- ⚠️ Сборник статей не ложится на книжный пайплайн → нужен входной слой нарезки на статьи (план, фаза 1a).
- Устойчивость LLM-извлечения утверждений нужно проверить отдельно до того, как верить числам.

## Revisit when
- Появится доступ к сильной модели (B(2), проверка совпадений утверждений).
- Решится вопрос «новизна не по теме» (фильтр релевантности).
