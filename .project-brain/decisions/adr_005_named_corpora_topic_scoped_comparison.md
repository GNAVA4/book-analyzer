# ADR 005: Именованные корпуса, тема документа, сравнение внутри темы
_Date: 2026-10-18 session 020 · Status: active_

## Context
Переход от скриптов к сервису: статью загружают и получают разбор по абзацам. Вопрос user:
из какого корпуса берётся сравнение, ведь «курсовая по методам моделирования» не должна
сравниваться со статьями по менеджменту, и нельзя каждый раз анализировать всё сразу.

## Decision
1. **Именованные корпуса** [user]: «КиберЛенинка», «Статьи этапа 2», далее «Курсовые», «Мивары»…
   При анализе выбирается корпус. Хранение — SQLite `data/corpus.db` (документ: разбор JSON,
   метаданные, тема; фрагмент: текст + эмбеддинг float32). Индекс — полный перебор numpy.
2. **Тема документа = область наук** (классификатор ОЭСР, как рубрики КиберЛенинки) [user: «надо
   учитывать тему»; конкретный словарь — inferred]. Источник: метка (`label`) или предсказание
   kNN (k=7) по центроидам размеченных документов ВСЕХ корпусов (`auto`, с уверенностью и голосами).
3. **С чем сравниваем** (scope): `topic` (по умолчанию) — документы той же темы, из них 10
   ближайших по coverage; `nearest` — 10 ближайших без учёта темы; `corpus` — весь корпус [inferred;
   «со всем корпусом тоже можно, но пока непонятно» — user].
4. **Опора**: фрагмент, у которого лучший фрагмент соседей < SUPPORT_SIM (0.56), — «не с чем
   сравнить», его новизна не входит в новизну статьи (session 019: новизна ≈ одиночество).
5. Быстрый проход (эмбеддинги + шинглы, секунды) — синхронно; уровень утверждений (LLM) — ещё
   не подключён к сервису (план: фоновая очередь).

## Alternatives rejected
- Один общий корпус: новизна зависит от случайного состава, темы смешиваются.
- Векторная БД (faiss/qdrant): избыточно до ~100 тыс. фрагментов.
- Тематическая кластеризация без меток: метки рубрик дёшевы и объяснимы.

## Consequences
- Тема угадывается в 75% (leave-one-out, 119 статей, 7 областей); ошибки — междисциплинарные
  статьи. Поэтому на странице показываются голоса и можно задать тему вручную.
- Области наук крупные: внутри области статьи о разном → у 60–65% фрагментов нет опоры. Для
  осмысленной новизны нужны ПЛОТНЫЕ по теме корпуса (сборники одной конференции, курсовые одного курса).
